# Brief-Making — Routing

**Purpose:** Governs all brief creation for this brand. Every brief (launch, campaign, IR, partnership, AEO, governance, reactive) follows the source-gathering step and the 5-pass methodology outlined here, and produces a one-page .docx in the canonical 6-question format.

## The Canonical Format: 6 Questions, One Page

Every the client brief answers these six questions, in this order, as a one-page Word document:

1. **What is it?**
2. **Why is it happening?**
3. **Who is involved?**
4. **When is it happening?**
5. **Where is it happening?** (e.g., "X, LinkedIn", "the client product app + the client product marketing site" for the client product, or "X, LinkedIn, YouTube" for the-client)
6. **How do we plan on doing it?**

This format is unified across all the client product engagements and is implemented by the `project-brief-skill` skill. Do not invent alternative structures. Do not skip, reorder, rename, or merge questions.

**Hard constraints:**
- One page maximum. No exceptions.
- Each answer short. If long, the detail belongs in a separate document.
- All six questions, in order, every time.
- Output is `.docx` titled `Project Brief: [Project Name]`.
