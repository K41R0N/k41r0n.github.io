# Methods archive

Source method files are kept in their source-area folders with mechanical identifier substitutions. These are references, not automatically certified packs. The previously reviewed copywriting and process-standardization packs remain in `agent/packs/` with their reviewed content.

- Import logs (substitution map, per-file counts, discarded paths) are kept in the owner's private reference storage, not in this public repo.

The import omits client-instance material, superseded brain content, corpus extraction outputs, prototypes, generated metadata and branded binaries.
