# How to use this brain

This file explains how to find things, how much to trust them, and how to change them. It applies to any surface: a chat assistant, a coding agent, or a person reading the files.

## Retrieval order

For a method or delivery question ("his method for X", "how do I show him HTML"), the first stop is deterministic: `python3 scripts/local/route.py "<the ask>"`. It routes to the corpus entry that answers the ask, or to the recovery contract - never a nearest-name guess. Then continue with the order below, starting at the routed document.

Look in this order and stop as soon as you have a sourced answer:

1. `index.md`: the repo map - what the site is, how it builds, where things live.
2. `AGENTS.md` and `CHARTER.md`: the rules and the scope. These override everything below.
3. `decisions/`: what is decided (`decisions/log.md`), what we are aiming at (`decisions/goals.md`), what is still unknown (`decisions/open-loops.md`), and voice findings (`decisions/voice-findings/`). A decision beats a knowledge note that disagrees with it.
4. `knowledge/`: `knowledge/ethos/` (his principles), `knowledge/methodologies/` (his ways of working - `knowledge/methodologies/method-sources.md` routes any method question to the right document across all harnesses, and its recovery contract governs dead ends), `knowledge/site/` (the site itself), `knowledge/voice/` (his voice canon), `knowledge/clients/` (durable public-source client research, one folder per client).
   The corpus index (`knowledge/methodologies/method-corpus.json`) and its router (`scripts/local/route.py`) stay in lockstep: adding an entry means adding its aliases and a behavioral case in `knowledge/methodologies/routing-cases.json`; `scripts/local/routing_lint.py` fails otherwise.
5. `routines/`: how the recurring jobs run, `routines/protocols/` (mandatory rules for multi-step operations), and `routines/learnings.md` for what earlier runs taught us.
6. `packs/`: his methods as importable modules, each with evals. `packs/index.md` routes a task to a pack.
7. `assets/`: the voice corpus and draft workspaces.

If the answer is not in the brain, say so and add an open loop. Do not fill the gap from memory.

## Trusting what you read

Every canon file states a `confidence` value. They rank like this, highest first:

| Value | Means | What you may do with it |
|---|---|---|
| `operator_reported` | Alejandro said it directly | Any internal use. External use only if the class and gates allow |
| `confirmed` | Checked against a cited source | Any use, including published copy |
| `reference` | Taken from a cited document, not independently checked | Internal reasoning. External use only when quoted and cited |
| `inferred` | Worked out by an agent from other items | Internal reasoning only. Never stated as fact externally |
| `conversation` | Said in a chat, call or voice note with no document behind it | Internal context only. Never in external content |

When two items disagree, the higher one wins, and the disagreement is worth an open loop. Some files mix entries of different strength; where that happens, each entry carries its own confidence and the per-entry value governs.

## Provenance

Every method, routine and skill doc states its origin on its face: his document or message (with date), his template, an external public source (cited), or built here from his description. A file that cannot state its provenance stops being used until he rules on it (see `CHARTER.md`, kill criteria).

## Writing to the brain

- Every canon file starts with the frontmatter contract: `id, type, title, description, confidence, source, updated, class, tags`, with types from `schemas/types.yaml` and tags from `schemas/tags.yaml`.
- Update `log.md` when you add or materially change a file.
- After adding, removing or renaming any pack, skill or routing-table row,
  run `python3 scripts/local/routing_lint.py`. It fails on unrouted packs,
  broken routing links, an incomplete method corpus registry and stale
  pointer files.
- Do not invent facts. If something is unknown, record it as an open loop in `decisions/open-loops.md`.
- `MANIFEST.md` is generated by `scripts/manifest.py`. Never edit it by hand.
