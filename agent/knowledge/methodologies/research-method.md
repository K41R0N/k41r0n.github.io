# Research method: fixed instruments and traceable evidence

Use this method for audience, market, contact, topic, and source research when the task needs a defensible synthesis rather than a link list.

## 1. Define the question and instrument

- State the decision or question the research should serve. If that is missing, ask before collecting data.
- Translate the question into a fixed set of fields. For an audience or entity profile, fields may include identity, context, relevance to the question, evidence of behavior, confidence, and open questions. Adapt the fields to the task, but keep them stable across comparable subjects.
- Write the behavioral or decision hypothesis before searching. State what evidence would support it, weaken it, or route it to another channel. Specify useful signal, noise, source scope, and a kill criterion. Keep ranking criteria and weights fixed across comparable runs; do not tune a run to fit a preferred result.
- Read the request in its surrounding context. A short ask may depend on an earlier thread or supplied artifact. Recover that context before deciding what to research.

## 2. Gather from a source ladder

1. Start with the most direct, authoritative sources available for the claim.
2. Use secondary sources to find leads and context, then verify consequential claims against the underlying source.
3. Record where and when each finding appeared. For changing facts, refresh them near the time they will be used.
4. Separate direct observation, reported information, inference, and recommendation. Do not promote an inference to a fact through repetition.
5. If sources disagree, show the competing values and explain which one the analysis uses. Preserve the disagreement until the source or definition resolves it.

## 3. Test hypotheses against more than one evidence surface

- For audience or market work, separate the source that explains a possible motive from the source that shows observed behavior. Label each separately; do not make an operator-reported explanation look like a measured behavior.
- Where feasible, test a hypothesis against both first-party evidence and an independent discovery or market surface. State what each can and cannot tell you.
- A search result with no volume can reject that channel as a capture route without disproving the underlying audience need. Route the hypothesis to a better-fitting surface, such as interviews, social listening, or editorial research, and name that as a channel decision rather than a failed research run.

## 4. Look for evidence that could change the answer

- Search for counterexamples and disconfirming evidence, not only support for the first hypothesis.
- For a causal explanation, identify the event, document, or mechanism that could explain the change. A plausible narrative without a supporting artifact is not a causal finding.
- In audience listening, track movement in language, behavior, or concerns over time. Volume and engagement alone are not evidence of a change in need.
- Distinguish audience groups and source surfaces where they may behave differently. Do not combine unlike samples into one average.

## 5. Synthesize and stop honestly

- Present a concise, ranked answer with the evidence and rationale attached to each conclusion.
- Name gaps, confidence, and what would settle the uncertainty. Do not fill missing fields with a generic persona or assumed typical case.
- Stop and ask a focused question when the evidence is too thin for a useful answer, when the key source is unavailable, or when a major claim depends on one weak source.
- Keep raw records separate from synthesis so another person can trace the path from source to conclusion.

## 6. Make repeated research comparable

Store the question, instrument version, source scope, search date, scoring rules, and known limitations with each run. Review the instrument when it fails, but change the rubric deliberately and version it rather than altering a single run invisibly. A number or ranking is meaningful only with its definitions, window, and source context.

This reusable procedure generalizes shared patterns; the output shape and task-specific fields below are synthesis, not a copied universal template. Choose fields, thresholds, and sources anew for each task.

## Minimal run record

Copy this block for a research run. Add fields only when they change the decision. Keep raw evidence separately from interpretation.

```text
Question / decision served:
Hypothesis (what might be true):
Evidence that would support it:
Evidence that would weaken it:
Evidence that would route it to a different channel:
Instrument version / fixed fields / scoring rules:
Sources and surfaces in scope (with what each can establish):
Search date / time window:
Kill or stop criterion:

Finding | source + date | observed / reported / inferred | confidence | limitation

Contradictions / missing fields:
Disposition: support / weaken / route / unresolved
Next evidence or question needed:
```

A zero-result surface is a channel result only when the search scope, time window, and instrument were adequate. Record those limits before routing the underlying hypothesis elsewhere.

## Output shape

1. Question and decision served
2. Scope, instrument, date, and stop rule
3. Findings in ranked order, each with source, date, evidence type, and confidence
4. What contradicts or limits the findings
5. Gaps and next evidence needed
6. Recommendation only when the evidence supports one; distinguish a channel-routing choice from a conclusion about the underlying need
