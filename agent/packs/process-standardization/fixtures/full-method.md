## Process Card: Handle a standard intake
- Source: Interview A, section 2
- Trigger: A complete request arrives.
- Purpose: Route the request to the person who can handle it.
- Inputs: Request details, required artifacts, assigned role family.
- Steps:
  1. Read the full request and linked materials.
  2. Record stated facts with a source location.
  3. Mark missing or contradictory details as open questions.
