# Copywriting methods

This pack stores a source-derived, generalized five-pass copywriting method as reference material. It includes the source-gathering routine and separate references for the big idea, factual anchoring, voice matching, storytelling structure, and final review.

Use these references when a request is to draft copy through the full five-pass method. The existing `copy-five-pass` pack remains the separate deterministic checker: it flags mechanical issues and does not write copy, judge voice, or approve a draft.

These notes are methods, not project policy, legal advice, or factual authority. Read the current brief and project-specific sources each time. The method does not grant approval to send or publish anything.
