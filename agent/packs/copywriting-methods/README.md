# Copywriting methods

This pack stores source-derived, generalized copy methods as reference material: the five-pass drafting method (with the source-gathering routine and separate references for the big idea, factual anchoring, voice matching, storytelling structure, and final review) and the five-pass review pipeline from his review engine (decontamination, creative review with five lenses and the Ogilvy filter, tone and voice, compliance, final page review).

Use these references when a request is to draft copy through the full five-pass method or to review copy against his framework. Read the source files fresh each run; a remembered checklist is not the method. The existing `copy-five-pass` pack remains the separate deterministic checker: it flags mechanical issues and does not write copy, judge voice, judge creative quality, or approve a draft. A clean lint result is not a pass on the method.

These notes are methods, not project policy, legal advice, or factual authority. Read the current brief and project-specific sources each time. The method does not grant approval to send or publish anything.
