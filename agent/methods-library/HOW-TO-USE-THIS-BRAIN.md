# How to use this repo

1. Open `index.md` and find the task you have.
2. Copy the pack folder into the agent that needs it. It is read-only there. Its files are hashed in the manifest so drift shows.
3. Run the pack's eval on its fixtures before relying on it.
4. If the pack gets a correction, log it in `routines/learnings.md` in this repo, not in the copy.
5. Never put client details in a pack. Run the push gate before pushing.
