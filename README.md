## 🌐 About This Repository (The Portfolio)

This repository is the source code and content backbone for my personal portfolio at [kairon.xyz](https://kairon.xyz). It functions as a heavily optimized, agent-native digital garden built without bloated frontend frameworks. 

### 🏗️ Architecture & Stack
- **Static Generation:** Vanilla HTML/CSS/JS generated by a custom lightweight Node.js build pipeline (`scripts/build.js`).
- **Headless CMS:** Sveltia CMS (Decap-compatible) for frictionless browser-based editing directly committing to `content/`.
- **Styling:** Bespoke CSS adhering to an editorial layout grammar (print-inspired metrics, margin notes, drop caps). No Tailwind, just semantic CSS.
- **GEO/AEO First:** Programmatic JSON-LD Schema.org generation, `llms.txt` and `llms-full.txt` endpoints designed specifically to feed AI search engines and crawler bots.

### 🤖 The OpenClaw Integration
This repository is deeply integrated into my **OpenClaw Personal Infrastructure** — a headless ASUS ROG Zephyrus G14 operating an ensemble of local AI agents.
- **The Research Agent:** Acts as a "Narrative Auditor," reading the live portfolio state (`llms-full.txt`) and comparing it against my private Obsidian vault. 
- **The Protocol:** Due to strict local execution boundaries (`SOUL.md`), the agent cannot push code. Instead, it drops structured Markdown/YAML updates into a synced outbox for me (or a coding agent) to approve and apply.
